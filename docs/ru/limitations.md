# Ограничения

[English version](../en/limitations.md) · [Telegram](telegram.md) · [Discord](discord.md) · [Прокси](proxy.md) ·
[Команды](commands.md) · [Решение проблем](troubleshooting.md)

Чего не позволяют MessageBridge, Telegram и Discord и как с этим жить.

## Telegram

| Ограничение | Что делать |
|-------------|------------|
| Один токен одновременно работает только в одном месте. Второй сервер или программа с тем же токеном получает `409 Conflict` | Отдельный бот на каждый сервер |
| Боты не видят сообщения других ботов | Ничего, так устроен Telegram |
| Бот без прав администратора с включённым режимом приватности видит только команды | Назначьте бота администратором, см. [Режим приватности](telegram.md#режим-приватности) |
| Примерно 20 сообщений в минуту в одну группу. Сверх этого — `429 Too Many Requests` | На активном сервере выключите сообщения о входе и выходе |
| Сообщение, которое пришло на сервер позже чем через 10 секунд после отправки, игнорируется | Синхронизируйте часы сервера (NTP) |
| Сообщения длиннее `max_telegram_message_length` (по умолчанию 90) удаляются и не пересылаются | Увеличьте значение в `config.yml` |
| Пользователи без @username показываются по имени. Если имя не проходит `display_name_regex`, сообщение удаляется | Оставьте `display_name_regex: ".*"`, чтобы пропускать любые имена |
| Пересылается только текст. Фото, стикеры, голосовые и файлы — нет | — |
| Одна группа и не больше одной темы в ней | — |
| После включения тем или перевода группы в публичную у неё меняется id | Плагин обновляет `chat_id`, когда Telegram сообщает о переезде, иначе выполните `mb telegram bind` ещё раз |
| Для привязки аккаунта Telegram нужен публичный @username | Задайте имя пользователя в **Настройках** Telegram |

## Discord

| Ограничение | Что делать |
|-------------|------------|
| Нужен включённый Message Content Intent, иначе Discord не пускает бота (код закрытия 4014) | Включите его в Developer Portal → **Bot** |
| Работает только HTTP-прокси, SOCKS5 — нет | Используйте HTTP-порт прокси-клиента |
| Один обычный текстовый канал. Каналы объявлений, ветки, форумы и голосовые каналы не подходят | — |
| Сообщения ботов и вебхуков не пересылаются | — |
| Сообщения чата идут через вебхук: боту нужно право «Управлять вебхуками», а в канале может быть не больше 15 вебхуков | Удалите лишние вебхуки канала |
| Бот может выдавать только роли ниже своей | Перетащите роль бота выше роли для привязки |
| Discord ограничивает, как часто можно менять тему канала, поэтому онлайн может обновляться с задержкой | — |

## Прокси

| Ограничение | Что делать |
|-------------|------------|
| SOCKS5 работает только для Telegram | Для Discord используйте HTTP |
| SOCKS5 с логином и паролем не поддерживается | Используйте HTTP или локальный клиент, который откроет HTTP-порт без пароля |
| Тот, кто держит сервер из `api_url`, видит токен бота | Используйте только свой сервер |

См. [proxy.md](proxy.md).

## Плагин

| Ограничение | Что делать |
|-------------|------------|
| `config.yml` перезаписывается при каждой загрузке, ваши комментарии теряются | Меняйте настройки командами `/mb`. Встроенные комментарии остаются |
| `config.yml` с ошибкой YAML не применяется, остаются прежние настройки | Исправьте строку из лога или из `mb reload`, см. [troubleshooting.md](troubleshooting.md#configyml) |
| В игре токены и пароли требуют `--unsafe`, потому что команды игроков пишутся в `logs/latest.log` | Задавайте их из консоли |
