## Где вводить

- **Консоль сервера или RCON:** без `/`, например `mb telegram check`. Токены и пароли лучше задавать здесь.
- **В игре:** с `/`, например `/mb telegram check`.

Всё, что меняется через `/mb`, сохраняется в `config.yml` и применяется сразу.

### `--unsafe`

Сервер записывает все команды игроков в `logs/latest.log`.
Поэтому в игре команду с токеном или паролем прокси нужно закончить `--unsafe`:

```
/mb telegram token 123456789:AAHd3... --unsafe
/mb discord proxy http proxy.example.com 3128 user password --unsafe
```

Без него команда не выполнится и ничего не сохранится. В консоли и через RCON `--unsafe` не нужен.

## Права

| Право                   | Что даёт                                                  | По умолчанию |
|-------------------------|-----------------------------------------------------------|--------------|
| `tbridge.setup`         | `/mb status`, `/mb telegram ...`, `/mb discord ...`       | op           |
| `tbridge.reload`        | `/mb reload`                                              | op           |
| `tbridge.unlink.player` | `/unlink <игрок>` — отвязать аккаунт другого игрока       | op           |

## `/mb`

| Команда       | Что делает                                                                               |
|---------------|------------------------------------------------------------------------------------------|
| `/mb`         | Справка                                                                                  |
| `/mb status`  | Состояние обоих ботов, группа и канал, прокси, последняя ошибка отправки сообщения       |
| `/mb reload`  | Перечитывает `config.yml` и `translations.yml`. Сообщит, если в `config.yml` ошибка      |

## `/mb telegram`

| Команда                                                                     | Что делает                                    |
|-----------------------------------------------------------------------------|-----------------------------------------------|
| `/mb telegram`                                                              | Пошаговая инструкция и текущее состояние      |
| `/mb telegram token <token> [--unsafe]`                                     | Задаёт токен бота                             |
| `/mb telegram chat <chat_id>`                                               | Задаёт группу                                 |
| `/mb telegram topic <topic_id\|none>`                                       | Задаёт тему, `none` — без темы                |
| `/mb telegram proxy <http\|socks5> <host> <port> [username] [password] [--unsafe]` | Задаёт прокси, см. [proxy.md](proxy.md) |
| `/mb telegram proxy off`                                                    | Убирает прокси                                |
| `/mb telegram api-url <url\|default>`                                       | Свой сервер Bot API, `default` — `api.telegram.org` |
| `/mb telegram bind`                                                         | Выдаёт код для привязки группы, см. ниже      |
| `/mb telegram check`                                                        | Проверяет токен, бота, режим приватности, группу, права, тему и отправляет тестовое сообщение |

`/mb telegram bind` показывает код. Отправьте `/bind <код>` в группу — в нужную тему, если темы включены.
Код действует 10 минут, отправить его должен администратор группы.
Подробнее — в [telegram.md](telegram.md#4-выберите-группу-и-тему).

## `/mb discord`

| Команда                                                               | Что делает                                           |
|-----------------------------------------------------------------------|------------------------------------------------------|
| `/mb discord`                                                         | Пошаговая инструкция и текущее состояние             |
| `/mb discord token <token> [--unsafe]`                                | Задаёт токен бота                                    |
| `/mb discord channel <channel_id>`                                    | Задаёт канал                                         |
| `/mb discord activity <text>`                                         | Задаёт статус бота, «Играет в <text>»                |
| `/mb discord proxy http <host> <port> [username] [password] [--unsafe]` | Задаёт HTTP-прокси, см. [proxy.md](proxy.md)       |
| `/mb discord proxy off`                                               | Убирает прокси                                       |
| `/mb discord bind`                                                    | Выдаёт код для привязки канала, см. ниже             |
| `/mb discord invite`                                                  | Ссылка, которая добавляет бота на Discord-сервер с нужными правами |
| `/mb discord check`                                                   | Проверяет токен, подключение, канал, права и отправляет тестовое сообщение |

`/mb discord bind` показывает код. Отправьте `!bind <код>` в нужный канал.
Код действует 10 минут, у отправителя должно быть право «Управлять каналом».
Подробнее — в [discord.md](discord.md#4-выберите-канал).

## Команды игроков

| Команда           | Что делает                                                           |
|-------------------|----------------------------------------------------------------------|
| `/link`           | Выдаёт код для привязки аккаунта Telegram или Discord                |
| `/unlink`         | Отвязывает ваш аккаунт                                               |
| `/unlink <игрок>` | Отвязывает аккаунт другого игрока. Нужно право `tbridge.unlink.player` |

## Команды ботов

Telegram:

| Команда       | Где                          | Что делает                                                     |
|---------------|------------------------------|----------------------------------------------------------------|
| `/vanilla`    | В связанном чате             | Список игроков онлайн                                          |
| `/link <код>` | В связанном чате             | Привязывает аккаунт Minecraft, код выдаёт `/link` в игре       |
| `/minfo`      | В любом чате                 | id чата, id темы и тип чата                                    |
| `/bind <код>` | В чате, который привязываете | Привязывает чат, код выдаёт `/mb telegram bind`                |

Команды Telegram работают и с именем бота: `/vanilla@my_server_chat_bot`.

Discord:

| Команда       | Где                            | Что делает                                            |
|---------------|--------------------------------|-------------------------------------------------------|
| `!vanilla`    | В связанном канале             | Список игроков онлайн                                 |
| `/link <код>` | В связанном канале             | Привязывает аккаунт Minecraft                         |
| `<код>`       | В личных сообщениях боту       | Привязывает аккаунт Minecraft                         |
| `!bind <код>` | В канале, который привязываете | Привязывает канал, код выдаёт `/mb discord bind`      |
