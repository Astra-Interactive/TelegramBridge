# Настройка Discord

[English version](../en/discord.md) · [Telegram](telegram.md) · [Прокси](proxy.md) · [Команды](commands.md) ·
[Решение проблем](troubleshooting.md) · [Ограничения](limitations.md)

MessageBridge пересылает сообщения между Minecraft и одним текстовым каналом Discord. Для этого нужен свой бот.
Сообщения из Minecraft приходят через вебхук, поэтому в Discord видны ник и аватар игрока.

## Быстрый старт

Команды удобнее всего вводить в консоли сервера. В консоли они пишутся без `/`.
В игре нужен `/` в начале, а после токена — `--unsafe` (почему — см. [Токен](#2-токен)).

1. Откройте [Developer Portal](https://discord.com/developers/applications), создайте приложение,
   откройте **Bot**, нажмите **Reset Token** и скопируйте токен. Там же включите **Message Content Intent**.
2. Выполните `mb discord token <токен>`
3. Выполните `mb discord invite`, откройте ссылку и добавьте бота на свой Discord-сервер.
4. Выполните `mb discord bind` и отправьте `!bind <код>`, который покажет плагин, в нужный канал.
5. Выполните `mb discord check` и исправьте всё, что он отметит как ошибку.

`mb discord` без аргументов покажет эти шаги и текущее состояние.

В России и некоторых других странах Discord заблокирован. Если `mb discord check` пишет,
что не может подключиться к Discord, сначала настройте HTTP-прокси: [proxy.md](proxy.md).

## 1. Создайте бота

1. Откройте <https://discord.com/developers/applications> и нажмите **New Application**.
2. Введите название, например `My Server`, примите условия и нажмите **Create**.
3. Откройте вкладку **Bot**.
4. Нажмите **Reset Token**, подтвердите и скопируйте токен. Discord показывает его только один раз.
5. На той же вкладке в разделе **Privileged Gateway Intents** включите **Message Content Intent**
   и нажмите **Save Changes**. Без этого Discord не пустит бота (код закрытия 4014).

Никому не показывайте токен: с ним можно управлять вашим ботом.
Если токен утёк, снова нажмите **Reset Token** и задайте новый — старый перестанет работать.

## 2. Токен

Из консоли или RCON:

```
mb discord token MTEx...
```

Из игры:

```
/mb discord token MTEx... --unsafe
```

Сервер записывает все команды игроков в `logs/latest.log`, так что токен окажется в логе.
`--unsafe` подтверждает, что вы это понимаете. В консоли он не нужен.

Можно и вручную вписать токен в `config.yml` (`jdaConfig.token`) и выполнить `mb reload`.

## 3. Добавьте бота на сервер

Выполните `mb discord invite`. Плагин выдаст ссылку, которая добавляет бота сразу со всеми нужными правами.
Откройте её, выберите свой сервер и нажмите **Авторизовать**. Ссылка появится, когда бот подключится.

Какие права нужны и зачем:

| Право                                      | Зачем                                                                          |
|--------------------------------------------|--------------------------------------------------------------------------------|
| View Channel (Просматривать каналы)        | Видеть канал                                                                   |
| Send Messages (Отправлять сообщения)       | Запуск и остановка сервера, ответы на команды                                  |
| Read Message History (Читать историю сообщений) | Ответы на команды                                                         |
| Embed Links (Встраивать ссылки)            | Сообщения о входе, выходе и смерти — это embed-сообщения                       |
| Manage Webhooks (Управлять вебхуками)      | Сообщения чата идут через вебхук `BRIDGE_HOOK_<channelId>` с ником и аватаром игрока |
| Manage Channel (Управлять каналом)         | Число игроков онлайн показывается в теме канала                                |
| Manage Roles (Управлять ролями)            | Только для роли, которая выдаётся при [привязке аккаунта](#привязка-аккаунтов) |

Если канал приватный или у него свои настройки прав, добавьте в канал бота или его роль
и разрешите там те же права.

Ссылку можно собрать и вручную: Developer Portal → ваше приложение → **OAuth2** → **URL Generator** →
scope `bot` → отметьте права из таблицы → откройте полученную ссылку.

## 4. Выберите канал

### Через код привязки (рекомендуется)

1. Выполните `mb discord bind`. Плагин покажет код, например `48213907`.
2. Отправьте `!bind 48213907` в канал, который хотите связать с сервером.
3. Плагин сам сохранит `channelId` и напишет, что привязал.

- Код одноразовый и действует 10 минут.
- У того, кто отправляет код, должно быть право **Управлять каналом** в этом канале.

### Вручную

1. В Discord откройте **Настройки пользователя** → **Расширенные** и включите **Режим разработчика**.
2. Нажмите на канал правой кнопкой → **Копировать ID канала**.
3. Выполните `mb discord channel 123456789012345678`

Канал должен быть обычным текстовым каналом на сервере, где есть бот.

## 5. Проверьте настройку

`mb discord check` проверяет токен, подключение, канал и права бота и отправляет тестовое сообщение.
Для каждой ошибки он пишет, что сделать.
`mb status` показывает оба бота, канал, прокси и последнюю ошибку отправки сообщения.

Если что-то не работает — см. [troubleshooting.md](troubleshooting.md).

## Статус бота

`mb discord activity play.example.com` — и у бота будет статус **Играет в play.example.com**.

## Прокси

Discord работает только через HTTP-прокси:

```
mb discord proxy http 127.0.0.1 10809
mb discord proxy off
```

Логин и пароль добавьте в конец, а в игре ещё и `--unsafe`. Подробнее — в [proxy.md](proxy.md).

## Привязка аккаунтов

1. Игрок пишет в игре `/link` и получает код.
2. Игрок отправляет `/link <код>` обычным сообщением в связанный канал
   или присылает боту в личные сообщения только код.

Чтобы при привязке выдавались роли, заполните блок `link` в `config.yml` и выполните `mb reload`:

```yaml
link:
  linkDiscordRole: "123456789012345678"   # id роли в Discord
  linkLuckPermsRole: "verified"           # группа LuckPerms
```

- Чтобы скопировать id роли, включите режим разработчика, откройте **Настройки сервера** → **Роли**,
  нажмите **...** рядом с ролью → **Копировать ID роли**.
- Боту нужно право **Управлять ролями**, а его роль должна стоять в списке выше той, которую он выдаёт.
  Перетащите роль бота повыше в **Настройки сервера** → **Роли**.
- `link: null` — роли не выдаются.

Игрок отвязывает аккаунт командой `/unlink`. Администратор с правом `tbridge.unlink.player` может выполнить
`/unlink <игрок>`.

## Настройки

Настройки лежат в `plugins/MessageBridge/config.yml` на Paper и Spigot
и в `config/MessageBridge/config.yml` на Forge и NeoForge, в блоке `jdaConfig`.

| Ключ        | По умолчанию | Что это                                     | Команда                       |
|-------------|--------------|---------------------------------------------|-------------------------------|
| `token`     | `""`         | Токен бота. Пустой — Discord выключен       | `mb discord token`            |
| `activity`  | `""`         | Статус бота, «Играет в ...»                 | `mb discord activity`         |
| `channelId` | `""`         | id текстового канала                        | `mb discord channel`, `bind`  |
| `proxy`     | `null`       | HTTP-прокси, см. [proxy.md](proxy.md)       | `mb discord proxy`            |

Пример:

```yaml
jdaConfig:
  token: "MTEx..."
  activity: "play.example.com"
  channelId: "123456789012345678"
  proxy: null
```

Плагин перезаписывает `config.yml` при каждой загрузке. Ваши комментарии пропадут, останутся только встроенные.

## Команды бота в Discord

| Команда       | Где                          | Что делает                                         |
|---------------|------------------------------|----------------------------------------------------|
| `!vanilla`    | В связанном канале           | Список игроков онлайн                              |
| `/link <код>` | В связанном канале           | Привязывает аккаунт Minecraft                      |
| `<код>`       | В личных сообщениях боту     | Привязывает аккаунт Minecraft                      |
| `!bind <код>` | В канале, который привязываете | Привязывает канал. Код выдаёт `mb discord bind`  |

## Что важно знать

- Сообщения ботов и вебхуков в Minecraft не пересылаются.
- Один сервер — один канал.
- Если роль для привязки выше роли бота, Discord не даст боту её выдать.

Подробнее — в [limitations.md](limitations.md).
