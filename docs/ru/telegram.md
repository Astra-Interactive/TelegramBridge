# Настройка Telegram

[English version](../en/telegram.md) · [Discord](discord.md) · [Прокси](proxy.md) · [Команды](commands.md) ·
[Решение проблем](troubleshooting.md) · [Ограничения](limitations.md)

MessageBridge пересылает сообщения между Minecraft и одной группой Telegram — или одной темой (топиком)
в группе с темами. Для этого нужен свой бот.

## Быстрый старт

Команды удобнее всего вводить в консоли сервера. В консоли они пишутся без `/`.
В игре нужен `/` в начале, а после токена — `--unsafe` (почему — см. [Токен](#2-токен)).

1. Откройте в Telegram [@BotFather](https://t.me/BotFather), отправьте `/newbot` и скопируйте токен.
2. Выполните `mb telegram token 123456789:AA...`
3. Добавьте бота в группу и назначьте администратором с правом **Удаление сообщений**.
4. Выполните `mb telegram bind` и отправьте в группу `/bind <код>`, который покажет плагин.
   Если в группе включены темы, отправьте код в ту тему, которую хотите связать с сервером.
5. Выполните `mb telegram check` и исправьте всё, что он отметит как ошибку.

`mb telegram` без аргументов покажет эти шаги и текущее состояние.

В России и некоторых других странах Telegram заблокирован. Если `mb telegram check` пишет,
что не может достучаться до Telegram, сначала настройте прокси: [proxy.md](proxy.md).

## 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`.
3. Введите имя — его увидят игроки в чате, например `Мой сервер`.
4. Введите username. Он должен заканчиваться на `bot`, например `my_server_chat_bot`.
5. BotFather пришлёт токен вида `123456789:AAHd3...` — цифры, двоеточие и около 35 символов.

Никому не показывайте токен: с ним можно читать чат и писать от имени бота.
Если токен утёк: @BotFather → `/mybots` → ваш бот → **API Token** → **Revoke current token**, затем задайте новый.

На каждый сервер — отдельный бот. Один токен одновременно работает только в одном месте,
см. [Один бот — один сервер](#один-бот--один-сервер).

## 2. Токен

Из консоли или RCON:

```
mb telegram token 123456789:AAHd3...
```

Из игры:

```
/mb telegram token 123456789:AAHd3... --unsafe
```

Сервер записывает все команды игроков в `logs/latest.log`, так что токен окажется в логе.
`--unsafe` подтверждает, что вы это понимаете. В консоли он не нужен.

Можно и вручную вписать токен в `config.yml` (`tgConfig.token`) и выполнить `mb reload`.

Бот подключится сразу, перезапускать сервер не нужно.

## 3. Добавьте бота в группу

1. Откройте группу → **Добавить участников** → найдите бота по username → добавьте.
2. Настройки группы → **Администраторы** → **Добавить администратора** → выберите бота.
3. Оставьте включённым **Удаление сообщений**. Остальные права боту не нужны.

Зачем боту права администратора:

- Он удаляет сообщения, которые не пересылает: длиннее `max_telegram_message_length`
  и от имён, которые не проходят `display_name_regex`. Для этого нужно право **Удаление сообщений**.
- Администратор видит все сообщения в группе, как бы ни был настроен режим приватности.

### Режим приватности

У новых ботов включён **Group Privacy**. Если бот не администратор и режим приватности включён,
он получает только команды — сообщения, которые начинаются с `/`. Обычные сообщения до Minecraft не дойдут.

Сделайте одно из двух:

- Назначьте бота администратором (так проще всего).
- Или выключите режим приватности: @BotFather → `/mybots` → ваш бот → **Bot Settings** → **Group Privacy** →
  **Turn off**. После этого удалите бота из группы и добавьте снова — Telegram применяет настройку, только когда бот
  заходит в группу.

`mb telegram check` сообщит, если бот не видит сообщения.

## 4. Выберите группу и тему

### Через код привязки (рекомендуется)

1. Выполните `mb telegram bind`. Плагин покажет код, например `48213907`.
2. Отправьте в группу `/bind 48213907`. Если в группе есть темы — отправьте в нужную тему.
3. Плагин сам сохранит `chat_id` и `topic_id` и напишет, что привязал.

- Код одноразовый и действует 10 минут.
- Отправить его может только администратор группы.
- Если бот молчит, он не видит сообщение. Назначьте его администратором или отправьте команду с именем бота:
  `/bind@my_server_chat_bot 48213907`.

### Вручную

1. Отправьте в группу (в нужную тему) `/minfo`. Бот ответит id чата, id темы и тип чата.
   `/minfo` работает в любом чате.
2. Выполните `mb telegram chat -1001234567890`
3. Выполните `mb telegram topic 12` или `mb telegram topic none`, если тема не нужна.

У групп отрицательные id. У групп с темами и других супергрупп id начинается с `-100`.

Подсказка: в закрытой супергруппе ссылка на сообщение или тему выглядит как `https://t.me/c/1234567890/12`.
id чата — это `-100` и первое число: `-1001234567890`.

### Что пересылается

| Группа       | `topic_id`       | Telegram → Minecraft                              | Minecraft → Telegram          |
|--------------|------------------|---------------------------------------------------|-------------------------------|
| Без тем      | пусто            | Все сообщения группы                              | В группу                      |
| С темами     | id темы          | Сообщения из этой темы                            | В эту тему                    |
| С темами     | пусто            | Сообщения из общей темы **General**              | В **General**                 |
| Без тем      | id сообщения     | Только ответы на это сообщение («ветка ответов») | Ответом на это сообщение      |

Последняя строка — для групп без тем: выберите сообщение, впишите его id в `topic_id`,
и переписка с сервером пойдёт в ответах к нему.
id сообщения — последнее число в ссылке на него: `https://t.me/c/1234567890/345` → `345`.

### Если id группы поменялся

Когда в группе включают темы, делают её публичной или меняют некоторые другие настройки,
Telegram превращает её в супергруппу. У супергруппы новый id, он начинается с `-100`.

Когда Telegram сообщает о переезде, плагин сам обновляет `chat_id`.
Если этого не произошло — например, сервер был выключен, — просто выполните `mb telegram bind` ещё раз.

## 5. Проверьте настройку

`mb telegram check` проверяет:

- токен и бота,
- режим приватности,
- группу: бот в ней состоит и видит её,
- права бота,
- тему,
- и отправляет тестовое сообщение.

Для каждой ошибки он пишет, что сделать. `mb status` показывает оба бота, группу, прокси
и последнюю ошибку отправки сообщения.

Если что-то не работает — см. [troubleshooting.md](troubleshooting.md).

## Настройки

Настройки лежат в `plugins/MessageBridge/config.yml` на Paper и Spigot
и в `config/MessageBridge/config.yml` на Forge и NeoForge, в блоке `tgConfig`.

| Ключ                          | По умолчанию | Что это                                                                 | Команда                     |
|-------------------------------|--------------|-------------------------------------------------------------------------|-----------------------------|
| `token`                       | `""`         | Токен бота. Пустой — Telegram выключен                                  | `mb telegram token`         |
| `chat_id`                     | `""`         | id группы                                                               | `mb telegram chat`, `bind`  |
| `topic_id`                    | `""`         | id темы, см. [Что пересылается](#что-пересылается)                      | `mb telegram topic`, `bind` |
| `max_telegram_message_length` | `90`         | Более длинные сообщения удаляются и не пересылаются                     |                             |
| `display_name_regex`          | `".*"`       | Имена пользователей без @username должны ему соответствовать, иначе сообщение удаляется |               |
| `proxy`                       | `null`       | Прокси для Telegram, см. [proxy.md](proxy.md)                           | `mb telegram proxy`         |
| `api_url`                     | `""`         | Свой сервер Bot API, пусто — `api.telegram.org`, см. [proxy.md](proxy.md) | `mb telegram api-url`     |

Пример:

```yaml
tgConfig:
  token: "123456789:AAHd3..."
  chat_id: "-1001234567890"
  topic_id: "12"
  max_telegram_message_length: 90
  display_name_regex: ".*"
  proxy: null
  api_url: ""
```

Плагин перезаписывает `config.yml` при каждой загрузке. Ваши комментарии пропадут, останутся только встроенные.

## Команды бота в Telegram

| Команда        | Где                     | Что делает                                                        |
|----------------|-------------------------|-------------------------------------------------------------------|
| `/vanilla`     | В связанном чате        | Список игроков онлайн                                             |
| `/link <код>`  | В связанном чате        | Привязывает аккаунт Minecraft. Код игрок получает командой `/link` в игре |
| `/minfo`       | В любом чате            | id чата, id темы и тип чата                                       |
| `/bind <код>`  | В чате, который привязываете | Привязывает чат. Код выдаёт `mb telegram bind`               |

Команды работают и с именем бота: `/vanilla@my_server_chat_bot`.

## Привязка аккаунтов

1. Игрок пишет в игре `/link` и получает код.
2. Игрок отправляет `/link <код>` в связанный чат.

У аккаунта Telegram должен быть публичный username (**Настройки** → **Имя пользователя**).
Если в `config.yml` заполнен блок `link`, игрок получит группу LuckPerms из `linkLuckPermsRole`.
Про блок `link` — в [discord.md](discord.md#привязка-аккаунтов).

## Что важно знать

### Один бот — один сервер

Telegram отдаёт сообщения бота только одной программе за раз. Если два сервера (или сервер и другая программа)
используют один токен, оба получают `409 Conflict: terminated by other getUpdates request`.
Создайте отдельного бота для каждого сервера.

### Другие ограничения

- Боты не видят сообщения других ботов.
- Telegram разрешает боту отправлять в одну группу примерно 20 сообщений в минуту.
- Сообщение, которое пришло на сервер позже чем через 10 секунд после отправки, игнорируется.
  Следите, чтобы часы сервера шли точно.
- Сообщения длиннее `max_telegram_message_length` удаляются и не пересылаются.

Подробнее — в [limitations.md](limitations.md).
