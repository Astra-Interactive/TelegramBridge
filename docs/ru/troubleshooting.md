# Решение проблем

[English version](../en/troubleshooting.md) · [Telegram](telegram.md) · [Discord](discord.md) · [Прокси](proxy.md) ·
[Команды](commands.md) · [Ограничения](limitations.md)

Ищите на странице текст ошибки (Ctrl+F). Тексты ошибок Telegram и Discord приходят на английском.

## С чего начать

1. `mb status` — оба бота, группа и канал, прокси и последняя ошибка отправки сообщения.
2. `mb telegram check` и `mb discord check` проверяют каждый шаг и говорят, что исправить.
3. Лог сервера — `logs/latest.log`. Строки плагина содержат `MessageBridge`.

В консоли команды вводятся без `/`. См. [commands.md](commands.md).

## config.yml

### Изменения в config.yml не применились: config.yml has an error and is not applied

В логе примерно так:

```
config.yml has an error and is not applied, the previous settings are kept: line 12, column 3: ...
```

В файле ошибка YAML. Плагин продолжает работать с прежними настройками и файл не трогает.
`mb reload` сообщит о той же ошибке.

Что делать:

1. Откройте `config.yml` на строке и столбце из сообщения.
2. Проверьте частые ошибки: табуляция вместо пробелов, неверный отступ, незакрытая кавычка,
   нет пробела после `:`.
3. Токены и id пишите в двойных кавычках: `chat_id: "-1001234567890"`.
4. Выполните `mb reload`.

Чтобы такого не было, меняйте настройки командами `/mb`, а не правкой файла.

### Пропали мои комментарии в config.yml

Плагин перезаписывает `config.yml` при каждой загрузке, поэтому ваши комментарии теряются.
Встроенные комментарии остаются.

## Telegram: токен и подключение

### 401 Unauthorized / 404 Not Found: неверный или отозванный токен

Токен неверный, с опечаткой или отозван в @BotFather.

Что делать: скопируйте токен заново в @BotFather → `/mybots` → ваш бот → **API Token** и выполните
`mb telegram token <токен>`. Токен выглядит как `123456789:AAHd3...` — без пробелов и без кавычек вокруг.

### 409 Conflict: terminated by other getUpdates request

Тот же токен использует другая программа: второй сервер, тестовый сервер, старая копия плагина
или другой бот. Telegram отдаёт сообщения бота только одной программе за раз.

Что делать: создайте в @BotFather отдельного бота для каждого сервера или остановите другую программу.
Если не знаете, кто ещё использует токен, отзовите его в @BotFather и задайте новый.

### Нет связи с Telegram: UnknownHostException, connect timed out

Сервер не может подключиться к `api.telegram.org`. Обычно Telegram заблокирован в стране или у хостинга.

Что делать: настройте прокси или свой сервер Bot API, см. [proxy.md](proxy.md).
Затем выполните `mb telegram check`.

### 429 Too Many Requests: retry after

Telegram разрешает боту отправлять в одну группу примерно 20 сообщений в минуту.
Активный чат на сервере или частые входы и выходы игроков превышают этот лимит.

Что делать: ошибка проходит сама. Если она частая, выключите `displayJoinMessage` и `displayLeaveMessage`
в `config.yml`.

## Telegram: группа и тема

### Bad Request: chat not found

Бот не знает такой чат.

- В `chat_id` опечатка. У групп отрицательные id, у супергрупп они начинаются с `-100`.
- Бота нет в группе.
- Группа стала супергруппой и получила новый id — см. следующий раздел.

Что делать: добавьте бота в группу и выполните `mb telegram bind`,
см. [telegram.md](telegram.md#4-выберите-группу-и-тему).

### Group chat was upgraded to a supergroup chat (migrate_to_chat_id)

Когда в группе включают темы, делают её публичной или меняют некоторые другие настройки,
она становится супергруппой с новым id. Когда Telegram сообщает об этом, плагин сам обновляет `chat_id`.

Если id не обновился: выполните `mb telegram bind` и снова отправьте код в группу.

### Bad Request: message thread not found / message to be replied not found

Тема из `topic_id` удалена или относится к другой группе.
В группе без тем `topic_id` — это id сообщения, и это сообщение удалили.

Что делать: выполните `mb telegram bind` и отправьте код в нужную тему или выполните `mb telegram topic none`.

### Forbidden: bot was kicked from the group chat / bot is not a member of the chat

Бота удалили из группы.

Что делать: добавьте его снова, назначьте администратором и выполните `mb telegram check`.

### Not enough rights: message can't be deleted / not enough rights to send text messages

Бот не администратор, у него нет права **Удаление сообщений** или участникам группы запрещено писать.

Что делать: настройки группы → **Администраторы** → бот → включите **Удаление сообщений**.
См. [telegram.md](telegram.md#3-добавьте-бота-в-группу).

### Сообщения из Telegram не доходят до Minecraft

Пройдите по списку:

1. **Режим приватности.** Бот без прав администратора с включённым Group Privacy видит только команды.
   Назначьте его администратором или выключите приватность в @BotFather и добавьте бота в группу заново.
   См. [Режим приватности](telegram.md#режим-приватности).
2. **Не та тема.** Пересылается только тема из `topic_id`. Если в группе с темами `topic_id` пустой,
   пересылается только **General**. См. [Что пересылается](telegram.md#что-пересылается).
3. **Не та группа.** Отправьте в группу `/minfo` и сравните id с `chat_id` в `mb status`.
4. **Часы сервера.** Сообщения, которые пришли позже чем через 10 секунд после отправки, игнорируются.
   Если часы сервера спешат или отстают, все сообщения кажутся старыми. Включите синхронизацию времени (NTP).
5. **Другой бот.** Боты не видят сообщения других ботов.
6. **Тот же токен в другой программе** — она забирает сообщения, см.
   [409 Conflict](#409-conflict-terminated-by-other-getupdates-request).
7. **Слишком длинное сообщение** или имя не проходит `display_name_regex` — такие сообщения бот удаляет.
   Пересылаются только текстовые сообщения.

### Сообщения из Minecraft не доходят до Telegram

1. `mb status` показывает последнюю ошибку отправки. Найдите её на этой странице.
2. Проверьте, что бот может писать в группу и тему: `mb telegram check` отправляет тестовое сообщение.
3. Сообщения о входе, выходе и смерти выключаются в `config.yml`: `displayJoinMessage`, `displayLeaveMessage`
   и `displayDeathMessage`.

## Discord

### Неверный токен: The provided token is invalid

Токен неверный или был сброшен в Developer Portal.

Что делать: Developer Portal → ваше приложение → **Bot** → **Reset Token**, скопируйте токен и выполните
`mb discord token <токен>`. Нужен токен со вкладки **Bot**, а не Client Secret со вкладки **OAuth2**.

### Disallowed intents (код закрытия 4014): включите Message Content Intent

Бот запрашивает у Discord текст сообщений, а Message Content Intent выключен.

Что делать: Developer Portal → ваше приложение → **Bot** → **Privileged Gateway Intents** →
включите **Message Content Intent** → **Save Changes**. Затем выполните `mb reload`.

### Нет связи с Discord: UnknownHostException, connect timed out

Сервер не может подключиться к Discord. Обычно Discord заблокирован в стране или у хостинга.

Что делать: настройте HTTP-прокси командой `mb discord proxy http <host> <port>`, см. [proxy.md](proxy.md).
Через SOCKS5 Discord не работает.

### Канал не найден: Could not find channel

- В `channelId` опечатка.
- Бота нет на этом Discord-сервере. Добавьте его по ссылке из `mb discord invite`.
- Бот не видит канал. Разрешите боту **Просматривать канал** в настройках канала.
- Канал не обычный текстовый: каналы объявлений, ветки, форумы и голосовые каналы не подходят.

Что делать: выполните `mb discord bind` и отправьте код в канал.

### Missing permission: MANAGE_WEBHOOKS, MESSAGE_SEND, VIEW_CHANNEL...

У бота нет права на то, что он пытается сделать. В сообщении указано, какого именно.

Что делать: выдайте боту это право на сервере и в настройках канала, если у канала свои права.
Проще всего заново добавить бота по ссылке из `mb discord invite`.
Список прав — в [discord.md](discord.md#3-добавьте-бота-на-сервер).

### Не удаётся создать вебхук (Manage Webhooks)

Сообщения чата из Minecraft отправляются через вебхук `BRIDGE_HOOK_<channelId>`. Бот создаёт его сам.

- У бота нет права **Управлять вебхуками** в канале. Выдайте его.
- В канале уже 15 вебхуков — это предел Discord. Удалите лишние в настройках канала
  → **Интеграции** → **Вебхуки**.

Плагин повторяет попытку каждые 30 секунд, перезапуск не нужен.

### Роль для привязки выше бота: Can't modify a role with higher or equal highest role

Бот может выдавать только роли ниже своей самой высокой роли.

Что делать: **Настройки сервера** → **Роли** → перетащите роль бота выше роли из `linkDiscordRole`.
Ещё боту нужно право **Управлять ролями**.

### В теме канала не показывается онлайн

Боту нужно право **Управлять каналом** в этом канале. Кроме того, Discord ограничивает,
как часто можно менять тему, поэтому число игроков может обновляться с задержкой.

### Сообщения из Discord не доходят до Minecraft

1. `mb discord check`: бот подключён и видит канал.
2. `channelId` — именно тот канал, куда вы пишете.
3. Message Content Intent включён.
4. Сообщения других ботов и вебхуков не пересылаются.

## Прокси

### Не прошла авторизация на прокси: 407 Proxy Authentication Required

Прокси не принял логин или пароль либо требует их, а они не заданы.

Что делать: задайте их заново, в игре — с `--unsafe` в конце:

```
mb telegram proxy http <host> <port> <username> <password>
mb discord proxy http <host> <port> <username> <password>
```

### SOCKS5 с паролем не поддерживается

SOCKS5 работает только без пароля и только для Telegram.
Java для паролей SOCKS требует глобальный аутентификатор, а плагин его не ставит.

Что делать: используйте HTTP-порт прокси. Если есть только SOCKS5 с паролем, запустите локальный прокси-клиент,
который подключится к нему и откроет HTTP-порт без пароля. См. [proxy.md](proxy.md).

### Discord не подключается через SOCKS5

Discord работает только через HTTP-прокси: его библиотека для websocket умеет только HTTP.

Что делать: `mb discord proxy http <host> <port>`. У локальных прокси-клиентов обычно рядом с SOCKS5-портом
есть и HTTP-порт.

### Неверный api_url

`api_url` — это адрес сервера Bot API, например `https://tg.example.com` или `http://127.0.0.1:8081`,
без `/bot<токен>` в конце.

Что делать: `mb telegram api-url <url>` или `mb telegram api-url default`, чтобы вернуть `api.telegram.org`.
См. [proxy.md](proxy.md#вариант-3-свой-сервер-bot-api-для-telegram).
